# بوت الخدمات التجارية لتيليجرام

بوت تيليجرام تجاري متكامل بنظام الرصيد وخصمه التلقائي، مقدم من المطور **@Aaaaaaq08pu**.

## الميزات

| الميزة | الوصف |
| --- | --- |
| نظام الرصيد | حفظ رصيد كل مستخدم في قاعدة بيانات SQLite، مع منع استخدام الخدمات عند انعدام الرصيد |
| أمر إضافة الرصيد | `/add [ايدي] [الرصيد]` خاص بالمطور (ايدي: 8858067249) |
| خدمة الرشق | رشق قنوات ومجموعات تلغرام (10 نقاط لكل طلب) عبر BuztGrowth المجاني |
| خدمة الأرقام الوهمية | أرقام مؤقتة مجانية لواتساب، تيليجرام، فيسبوك وغيرها (5 نقاط لكل رقم) |
| أزرار تفاعلية | InlineKeyboard كاملة (القائمة الرئيسية، الرصيد، الطلبات، الشراء) |
| إحصائيات | أمر `/stats` للمطور لعرض عدد المستخدمين والطلبات والنقاط |

## أوامر البوت

- `/start` — بدء البوت وعرض القائمة الرئيسية
- `/help` — تعليمات الاستخدام
- `/balance` — عرض الرصيد الحالي
- `/spam` — بدء خدمة رشق القنوات
- `/numbers` — بدء خدمة الأرقام الوهمية
- `/add [ايدي] [الرصيد]` — إضافة رصيد (للمطور فقط)
- `/stats` — إحصائيات البوت (للمطور فقط)
- `/cancel` — إلغاء أي عملية جارية

## التثبيت والتشغيل

```bash
pip install -r requirements.txt
playwright install chromium
python bot.py
```

عند استخدام جسر Telegram API المنشور، اضبط المتغير التالي قبل التشغيل ثم أعد تشغيل البوت:

```bash
export TELEGRAM_RELAY_URL="https://YOUR-RELAY-DOMAIN"
python bot.py
```

لا تشغّل سوى نسخة واحدة من البوت بالرمز نفسه عند استخدام `getUpdates`. استجابة `409 Conflict` تعني أن نسخة أخرى ما زالت تستقبل التحديثات بالرمز نفسه.

يمكن التحقق محلياً من منطق الروابط دون الاتصال بتيليجرام:

```bash
python -m unittest -v test_validation.py
```

## الاستضافة

المشروع جاهز للاستضافة على **Render** (الوضع المجاني) أو **Heroku** عبر ملف `Procfile`.

## تخصيص الخدمة

- تكلفة الخدمات قابلة للتعديل من الثوابت أعلى ملف `bot.py`:
  `SPAM_SERVICE_COST = 10` و `NUMBERS_SERVICE_COST = 5`
- مزود الرشق الحالي: BuztGrowth (مجاني، بحد طلب واحد لكل 6 ساعات لكل رابط).
- مزود الأرقام الحالي: receive-smss.com (مجاني بالكامل).
- في حال أردت تغيير المزودين، عدّل الدالتين `spam_service_boost()` و `get_all_temp_numbers()`.
- روابط الدعوة الخاصة بصيغة `t.me/+...` صحيحة من ناحية التنسيق، لكنها لا تصلح لطلبات مزود الرشق الخارجي؛ استخدم رابط قناة أو مجموعة عامة لهذه الخدمة.
- لا يمكن اعتماد بوت أرقام خارجي كمزوّد تلقائي من اسمه فقط. يتطلب ذلك API موثقاً وبيانات اعتماد من مالكه، أو تفعيل وضع تواصل البوتات لدى البوتين معاً.
